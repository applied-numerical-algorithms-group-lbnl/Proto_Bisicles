\section{Notation}
Given constants $\alpha, beta$,
the viscous tensor operator takes the form
\begin{equation}
  L(\vel) = \alpha A \vel + \beta Div(F)
\end{equation}
Where the flux $F$ is given by
\begin{equation}
  F(\vel) = eta*(grad(\vel)  + grad(vel)^T) + lambda*I*div(vel)
\end{equation}
